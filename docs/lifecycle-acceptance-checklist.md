# OneDay 生命周期旅程发版验收门（#19）

发版前固定执行一次（手工约 10 分钟），4 条核心旅程全部通过才允许对外放量。

## 1. 全新安装（Fresh Install）
- [ ] 冷启动无闪退，进入引导/连接页，连接状态提示为人话。
- [ ] 输入服务器地址与密钥（或扫码配对）后成功握手，`/v1/capabilities` 正常拉取。
- [ ] 主线对话发送首条消息并收到完整流式回复；新建一条旁聊，标题能正常回流。
- [ ] 通知授权弹窗正常，推送就绪页如实显示权限与服务端登记状态（不假报成功）。

## 2. 卸载重装（Reinstall + 历史恢复）
- [ ] 卸载旧包后重装同版本，重新连接同一服务端。
- [ ] 打开主线与历史旁聊，分页拉取历史消息正常（无 `400 invalid_pagination` 报错）。
- [ ] 历史消息中的图片、Markdown 表格、代码块渲染完整，长表格列宽受控且可横滚。

## 3. 覆盖升级（In-Place Upgrade）
- [ ] 从上一正式版直接覆盖安装待发新版本，冷启动迁移 SwiftData 无闪退。
- [ ] 原有本地草稿、置顶/归档会话、连接配置与模型选择保持不变。
- [ ] 模拟旧版/低版本触发 `VersionCompatibilityGate`：软提示可关闭，强阻断有明确升级说明。

## 4. 换机 / 多设备接入（Device Switch）
- [ ] 旧设备生成配对码，新设备扫码认领成功并拉取历史会话列表。
- [ ] 断网重连与 401 鉴权失效时，错误提示走顶部玻璃 Toast 人话文案，不直接暴露内部错误码或英文堆栈。
- [ ] 触发一次模拟异常/检查崩溃采集页，确认诊断脱敏与上传链路可用。
