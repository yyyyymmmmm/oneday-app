# OneDay 侧边栏调研笔记（2026-11-09，0.3.6 依据）

用户令：侧边栏找成熟项目借鉴、先调研。本文档为调研
收敛稿：参照结构 → 逐项借/不借 → OneDay 侧栏规格 v2。

## 一手与二手来源

- **Muse 本体（用户真机截图，一手）**：聊天页顶栏＝
  侧栏钮＋标题胶囊（会话名＋模型名）＋新建钮；抽屉自
  左滑出覆盖主面，内为搜索＋会话列表＋底部用户行。
  OneDay 顶栏已同构（0.2.x 定版），本轮只动抽屉内部。
- **ChatGPT 本体结构（UX 规格整理：samfoy/pi-dashboard
  ios-ux-spec §1、Meliwat/awesome-ios-design-md 的
  ChatGPT DESIGN.md）**：抽屉宽约 82%、scrim 约 0.4；
  搜索在顶（实时按标题过滤）；新建行在搜索下；列表
  按最近活跃倒序，时间分组＝今天／昨天／过去 7 天／
  过去 30 天／更早按月名；分组标题小号（12pt/500）
  灰字；会话行＝单行标题（15pt/500）截断，无行内元
  数据；选中行＝中性浅灰圆角填充（#ECECEC）；左滑
  ＝删除/归档、右滑＝置顶（版本相关）；长按菜单＝
  重命名/分享/归档/删除；底部用户行钉底；面板底色
  比画布略深一档（#F9F9F9 对白画布）。
- **Claude 本体（同上规格 §1）**：现行版为全屏列表＋
  push 导航（非抽屉，与用户截图中的抽屉形态是不同版
  本线）；行＝标题（粗、单行）＋末条预览（灰、1–2
  行）＋右侧相对时间；分组同 ChatGPT 五段；左滑仅
  删除；长按＝重命名/删除。
- **开源实现**：
  - bryanrg22/chatgpt-ios-ui（SwiftUI 复刻 ChatGPT
    1.2026 的 UI 骨架包，含 sidebar 屏）：结构与上
    述规格互证——抽屉＋搜索＋分组列表＋底部行；只
    借结构观察，不引库（复刻包、无真实数据层）。
  - Exyte/Chat、Stream Chat：成熟在消息列表与发送
    舱（OneDay 已采用其承载结构），无会话抽屉，不
    在本轮参照系。
  - Open-Relay（Open WebUI 的原生 iOS 客户端，已上
    架）：自托管 AI 客户端的同类问题——会话在服务
    端、抽屉即会话入口；其 IA 取向（抽屉只管会话、
    管理面另置）与 OneDay 现状（服务端会话在设置里
    管理、抽屉尾组只做索引入口）一致，互证不改 IA。

## 逐项借 / 不借

| 项 | 参照做法 | 借否 | 理由 |
|---|---|---|---|
| 时间分组五段（今天/昨天/7天/30天/更早按月） | ChatGPT＋Claude 一致 | **借** | 现三段（今天/昨天/更早）粒度太粗，老会话全挤一坨；五段是两家共识，纯逻辑可单测 |
| 会话行单行标题、无行内元数据 | ChatGPT | **借** | 现行双行「N 条 · M月d日 HH:mm」是管理台气质；参照行内只留标题，时间信息归分组标题 |
| 选中行中性填充＋标题半粗 | 两家一致（#ECECEC 同理） | **借（已半有）** | 现已有 fieldFill 填充＋semibold，保留并对齐新行高 |
| 左滑删除／右滑置顶（List swipeActions） | ChatGPT | **不借（本轮）** | 面板拖拽关闭与行滑行同为横向拖拽：抽屉面板挂着 DragGesture（横向优先接管），SwiftUI 仲裁下行滑行会被饿死成静默无效；三件操作先由长按菜单全量承接，待真机手感轮把面板拖拽改到头部/底部承载后再开滑行 |
| 长按菜单补重命名＋置顶 | 两家一致 | **借** | 现长按只有删除。自动标题只覆盖「新会话」占位（ChatView 首条消息处），改名不会被后续消息冲掉，安全 |
| 置顶组 | ChatGPT | **借** | ChatThread 加 isPinned（默认 false，SwiftData 轻量迁移）；置顶组内仍按活跃倒序 |
| 面板右侧圆角＋浮层阴影 | 两家面板均有柔和阴影/圆角收尾 | **借** | 现面板方形无影、贴边生硬；圆角 24＋Elevation.floating |
| 拖拽越界橡皮筋 | Apple 材质口径（审查备忘录 E-3 已立项） | **借** | 现硬钳制有撞墙感；越界段套 0.55 橡皮筋公式，界内 1:1 不变 |
| 搜索置顶胶囊＋实时过滤 | 两家一致 | **已有** | 现实现即如此（标题＋正文过滤，比参照只按标题更宽，保留） |
| 新建行（搜索下）＋顶栏新建钮双入口 | 两家一致 | **已有** | 现实现即如此 |
| 底部账号行 | 两家钉底 | **已有（对应物）** | OneDay 的对应物＝底部服务器行（状态点＋主机名→设置），保留 |
| 身份头 | Muse 侧栏顶部品牌/账号 | **已有** | 现 drawerIdentity（Hermes＋状态点＋状态词·模型）即 OneDay 的身份头，保留 |
| Claude 全屏列表＋push 导航 | Claude 现行版 | 不借 | OneDay IA 是抽屉覆盖聊天面（0.2.x 定版、顶栏侧栏钮已成型），换导航形态是 IA 级推翻，不在本轮 |
| Claude 行「标题＋预览＋相对时间」双行 | Claude | 不借 | 与 ChatGPT 单行标题取一即可；OneDay 会话标题为首条消息截断、自带信息量，预览行冗余 |
| Projects／GPTs／探索入口 | ChatGPT | 不借 | OneDay 无此 IA，硬塞即编功能 |
| 归档（左滑/菜单） | ChatGPT | 不借 | 数据模型无归档态；删除已够用，不为对齐而造状态 |
| 删除二次确认流 | ChatGPT | 不借（本轮） | 与 OneDay 既有长按删除的即时口径一致；破坏性操作口径要改应全局统一，不在侧栏单点改 |
| 服务端会话组（抽屉尾） | 参照无对应 | **保留（OneDay 特有）** | 服务端会话是 Hermes 真身、用户要从抽屉直达详情（既有接线 onOpenServerSession）；行保留副行「N 条 · 日期」（管理对象、与本机会话行分域），样式对齐新行距 |

## OneDay 侧栏规格 v2（0.3.6 落地口径）

1. 骨架不动：左抽屉覆盖式，宽 82%／上限 340；开合
   ＝顶栏钮＋左缘手势＋面板拖拽＋点 scrim；开合动
   效走 MotionTokens.dragSpring、Reduce Motion 瞬
   时（既有机制，含预测位移定去向）。
2. 面板：底 Palette.surface；右侧圆角 24
   （continuous，UnevenRoundedRectangle）；浮层阴
   影 Elevation.floating；拖拽越界段橡皮筋（界内
   1:1；公式见 OneDayCore.DrawerGeometry）。
3. 结构自上而下：身份头 → 搜索胶囊 → 新建会话行
   → 会话列表（List 化）→ 底部服务器行 → 底栏留位
   （原生底栏浮于抽屉之上的既有层级不动）。
4. 分组（纯逻辑 OneDayCore.SidebarGrouping，单测
   把守）：置顶（有才出现）→ 今天 → 昨天 → 过去
   7 天 → 过去 30 天 → 更早按月（同年「M月」、跨
   年「yyyy年M月」）；组内按 updatedAt 倒序；搜索
   时单组「搜索结果」（置顶不单列、按时间序）。
   分界按自然日差：0 今天、1 昨天、2–7 过去 7 天、
   8–30 过去 30 天、>30 按月。
5. 本机会话行：单行标题（TypeScale.callout；当前
   会话 semibold＋Palette.fieldFill 圆角填充，其余
   regular/透明），行高 44，左右内距与组标题对齐
   线一致；无元数据行。
6. 行操作：长按菜单＝置顶/取消置顶、重命名、删
   除（destructive）。滑行操作本轮不上（手势仲裁，
   见借/不借表），长按全量承接。重命名走 alert＋
   TextField，写入 ChatThread.title 并 save。
7. 数据：ChatThread 加 isPinned: Bool = false
   （SwiftData 轻量迁移）；切换/改名/删除均经既有
   modelContext 通道 save。
8. 服务端会话组：List 尾组，标题「服务端会话」；
   行保留两行（标题 callout＋「N 条 · M月d日」
   monoCaption），点行关抽屉去设置详情（既有接
   线）；空时一行去向说明（既有）。
9. 空态：无会话/无匹配各一行弱字（既有文案）。
10. 令牌纪律：颜色/字阶/间距只走 Palette、
    TypeScale、OneDayMetrics；选中填充归中性面
    （§19 变/不变表：主题色不进列表选中填充，
    与 0.3.3 既定「近单色纪律」一致）。
