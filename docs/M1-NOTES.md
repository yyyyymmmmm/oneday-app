## 色彩与对比度实测（WCAG 公式逐对验算）

基色：腾讯蓝 #0052D9。浅底全部 ≥4.5:1：
- primary 对页面底 5.89 / 对卡面 6.54 / 对浅蓝底 5.77
- 正文墨对页面底 14.21；次级灰对页面底 5.28 / 对卡面 5.86
- 白字对深蓝填充 9.40

深色模式为何不用本体蓝：#0052D9 对深色页底仅 2.80:1、对深色卡面
2.48:1（实测），达不到 4.5:1，故主色提亮为 #6BA3FF：
- 提亮蓝对页底 7.25 / 对卡面 6.41 / 对深蓝染色底 5.54
- 填充仍用 #0052D9（白字对其 6.54:1）；正文墨 16.15、次级灰 7.41

## 取舍与遗留

1. **ATS**：Info.plist 仅开 NSAllowsLocalNetworking（自托管常在局域网）。
   公网 http:// 地址连不上，连接页给「不安全地址」的明确报错；
   若后续要支持公网 http，改走逐域名例外而不是全放开。
2. **聊天记录只存本地**：服务端 /api/sessions 已实测存在，
   但本地与服务端会话未打通（里程碑 2 决策：以服务端为准同步，
   还是本地独立存档）。
3. **Markdown 是子集实现**：段落/标题/行内样式/代码块够聊天用；
   表格、列表、图片、链接跳转未做（里程碑 2 评估换完整解析器）。
4. **流式跟随滚动**：每个分片都滚到底，接近正式产品行为；
   长回复的滚动性能待真机验证，必要时加节流。
5. **图标是占位**：蓝色渐变＋白色「1」（程序生成 1024 PNG），
   正式图标走 app-icon 流程后替换同名文件即可。
6. **断开连接保留聊天记录**：只清凭据与会话；记录随 App 数据
   删除而消失，设置页文案已写明。
7. **对话模型 id**：取 /v1/models 首项（现为 hermes-agent），
   模型切换是里程碑 2「模型与配置」的事。
