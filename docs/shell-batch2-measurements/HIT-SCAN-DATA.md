# 胶囊命中域扫描数据（2026-11-12）

## 实验设计

**目标**：对三种胶囊形态进行全宽命中扫描，记录每个落点触发的动作

**扫描环境**：
- 同宿主：真实容器装配（ChatView顶栏）
- 容器静止态：抽屉关闭、无动画
- 扫描方式：胶囊全宽逐点点按
- 扫描粒度：每8pt一个采样点
- 记录内容：x偏移（相对胶囊左缘）→ 触发动作（枢纽/模型/无响应）

**三组对照**：

### ①组：现行形态（0.50.22 IdentityCapsuleView）
- 背景玻璃背板：`.background { Capsule().fill(.clear).glassEffect(.regular) }`
- 两个独立Button：身份域 + 模型域
- 按压样式：`.buttonStyle(.odPressable)`
- 发丝线分隔：0.5pt Rectangle

### ②组：历史形态（0.49.3 capsuleRow）
- 行本体玻璃：`.glassEffect(.regular, in: Capsule())` 直接挂HStack
- 身份域：Button
- 模型域：原生Menu + Picker
- 按压样式：`.buttonStyle(.odPressable)`

### ③组：苹果官方定式（裁决构造）
- `GlassEffectContainer` 包裹
- 两钮各自：`.glassEffect(.regular.interactive(), in: Capsule())`
- 拼合：`.glassEffectUnion(id: "identity-capsule")`
- 无`.odPressable`：系统玻璃按压行为接管
- ViewThatFits两档：全量（头像+名+状态+模型）/ 紧凑（去名字）
