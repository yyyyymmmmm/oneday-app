## 一、未单列小件 9 件

| # | 小件 | 结论 | 依据／卡点／去留 |
|---|------|------|------------------|
| 小1 | 会话置顶 | **未补齐·遗留（写口）** | 读口在：dashboard 会话列表（9119，cookie 通道）条目带 `pinned` 字段，实测在位。写口不在插件可达面：浏览器可达的 9119 `PATCH /api/sessions/{id}` 走上游修订围栏协议（`web_server_sessions.py`：须带 request_id＋expected_revision＋operation 信封，裸 PATCH 实测回 409 `client_upgrade_required`），那是上游桌面端的编辑协议，网页 SPA 自身也不做置顶管理（web_dist 产物内 `pinned` 仅 2 处散字、Sessions 页无置顶 UI，与差集清单原判一致）；网关 8642 有直写 PATCH（App／桌面侧栏口径，字段白名单 title/pinned/archived/hidden/unread），但公网 `/api/sessions/{id}` 落 9119、无接线到 8642，且按方法把 PATCH 分流去 8642 会让 dashboard 自家会话编辑的围栏字段被网关 handler 判 400 打断，风险不对等，本棒不硬上。去留：留待上游网页会话编辑协议稳定，或单独立 nginx 接线小单（必须带 dashboard 会话编辑回归验证）再补 |
| 小2 | 未读分隔／已读回执 | **未补齐·遗留** | 聊天面是 xterm 终端画布，插件无自有聊天面可嵌未读分隔线（与差集 #19 同族约束）；会话条目虽带 `unread` 字段，但呈现面是 dashboard Sessions 页、插件不接管。去留：同 #19，待上游聊天面形态变化（出 DOM 聊天）再议 |
| 小3 | 图片独立查看器 | **✅ 补齐（插件 0.7.0）** | 纯前端 lightbox：动态帖配图、文件库图片预览、身份面头像三处图片可点击打开全屏查看，Esc／点击关闭；零后端、零新接口 |
| 小4 | 崩溃报告面 | **✅ 补齐（插件 0.7.0）** | 接口现成：`GET /v1/diagnostics/crash-reports`（网关 crash_reports 模块，App 隐私门白名单＋服务端脱敏留存）。诊断面只读呈现：类型（崩溃/卡死/CPU 异常/磁盘写异常/其他）、捕获时间、App 版本、系统版本、异常类型/信号、终止命名空间/码、故障线程前 3 个符号。实测现行 instance 有 1 条真记录（2026-11-23，App 0.50.101）字段齐 |
| 小5 | 连接自检一键面 | **✅ 补齐（插件 0.7.0）** | 诊断面「一键自检」六探针逐项出通过/失败与读数：网关健康 /health、网关能力 /v1/capabilities、凭据链（reveal 换钥→待批读取）、插件名册 /api/dashboard/plugins、插件资产路由、定时任务投影 /api/jobs。与 dashboard System 页 doctor 的分工：doctor 是上游运维口径，本自检是 OneDay 链路口径（差集清单原注「doctor 近似、形态不同」，本件即补 OneDay 口径那一面） |
| 小6 | 聊天诊断面 | **未补齐·遗留** | 网关与 dashboard 均无聊天诊断数据面（没有可读接口，造面即造数据，违真数据口径）；日志侧由 dashboard Logs 页覆盖，诊断面已注记此分工。去留：未来服务端若立聊天诊断数据面再补，本棒不造 |
| 小7 | 演示模式 | **不补** | 网页控制台是部署者本人的运维面，全线口径只呈真数据；演示模式（假数据展示）与之相悖。App 侧演示属对外展示场景，网页端无此场景 |
| 小8 | 枢纽·邮件面 | **不补** | App 形态是内嵌浏览器节；网页端用户就在浏览器里、邮件自有其网页宿主，内嵌一层无对位价值（差集清单同判低优先） |
| 小9 | 推送通知设置 | **✅ 补齐基础形态（插件 0.7.0）** | 诊断面「待批提醒」：Notification API 授权＋页内 30 秒轮询待批数、出现新增待批弹浏览器通知，开关存 localStorage（本机口径）。未接部分明示记遗留：服务端 Web Push（关页也能推）需新后端（订阅存储＋VAPID 密钥＋发送链），不在本棒零新后端口径内，待点名再立单 |

小结：9 件＝补齐 4（小3/4/5/9，其中小9 为基础形态、Web Push 半件记遗留）、遗留 3（小1/2/6，均写明卡点）、不补 2（小7/8，产品口径）。
